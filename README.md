# Acculux-device
**Capstone Project: Development of a Pressure and Navigation System For Nirscan Probe for Breast Cancer Detection**

The objective of this project is to add functionality to the existing NIR Imaging Inc. device in the way of:
 - Orientation tracking
 - Positional tracking
 - Force sensing

Download the latest software release here: https://github.com/jjhcwoo/Acculux-device/releases/latest
